# Breathe ESG Assignment

## Project Overview

This project is an ESG data ingestion and review platform.

Users can:
- Upload ESG CSV files
- Normalize emission values
- Detect suspicious records
- Review and approve/reject records
- View dashboard summaries

## Tech Stack

### Backend
- Django
- Django REST Framework
- SQLite

### Frontend
- React
- Vite
- Axios

## Features

- CSV Upload API
- Data normalization
- Suspicious record detection
- Approval/rejection workflow
- Dashboard statistics
- Admin panel
